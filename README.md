# دستیار هوشمند حقوقی (AI Legal Assistant)

این پروژه یک نرم‌افزار دسکتاپ است که با استفاده از مدل‌های زبان بزرگ (LLM) و تکنیک RAG (Retrieval-Augmented Generation)، به کاربران امکان تحلیل و بررسی قراردادها و اسناد حقوقی را می‌دهد. کاربر می‌تواند اسناد مرجع (پایگاه دانش) و قراردادهای مورد نظر خود را بارگذاری کرده و از طریق یک رابط چت، سوالات خود را بپرسد.

## 🎯 درباره پروژه

هدف اصلی این دستیار، فراهم کردن ابزاری هوشمند برای وکلا، کارشناسان حقوقی و مدیران قرارداد است تا بتوانند با سرعت و دقت بالا، مفاد قراردادها را بر اساس قوانین و بخش‌نامه‌های مرجع، تحلیل و مغایرت‌های احتمالی را شناسایی کنند. این سیستم با استفاده از مدل‌های زبان محلی (Local LLMs) مانند Llama 3، حریم خصوصی داده‌ها را تضمین می‌کند، زیرا هیچ اطلاعاتی به سرورهای خارجی ارسال نمی‌شود.

## ✨ ویژگی‌ها

- **رابط کاربری مدرن و کاربرپسند**: طراحی شده با PyQt6 برای تجربه‌ی کاربری روان.
- **پشتیبانی از مدل‌های زبان محلی**: امکان انتخاب و استفاده از مدل‌های مختلف از طریق Ollama.
- **ایجاد پایگاه دانش پویا**: بارگذاری اسناد حقوقی (PDF, DOCX, و ...) به عنوان منبع اطلاعاتی برای مدل.
- **تحلیل همزمان چند قرارداد**: امکان بارگذاری و پرسش در مورد چندین قرارداد به صورت همزمان.
- **پرسش و پاسخ به زبان طبیعی**: تعامل با سیستم از طریق یک پنجره چت هوشمند.
- **تضمین حریم خصوصی**: تمام پردازش‌ها به صورت محلی انجام شده و داده‌ها از سیستم شما خارج نمی‌شوند.
- **عملکرد سریع**: استفاده از پایگاه داده‌ی برداری (FAISS) برای بازیابی سریع اطلاعات مرتبط.

## 🛠️ تکنولوژی‌های استفاده شده

- **زبان برنامه‌نویسی**: Python 3.10+
- **رابط کاربری (UI)**: PyQt6
- **پردازش زبان طبیعی (NLP)**:
  - **LangChain**: برای ساخت و مدیریت زنجیره RAG.
  - **Ollama**: برای اجرا و مدیریت مدل‌های زبان بزرگ محلی (مانند Llama 3).
- **پایگاه داده برداری (Vector Store)**: FAISS
- **پردازش اسناد**: PyMuPDF, python-docx
